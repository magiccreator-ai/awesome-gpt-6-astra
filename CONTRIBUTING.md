# Contributing

## Suggest a demo

Open an issue with the **Suggest a demo** template. You do not need to edit JSON.

Please provide:

- A link to the original creator's post and their name or handle.
- A short explanation of what was built and how Astra was involved.
- A live demo or source-code link, if the creator made one available.
- Other tools used, known limitations, and any sponsorship disclosure.

We collect concrete projects and workflows, not standalone prompts, reposts without attribution, or unverified benchmark claims. A recording is fine when no live demo exists; do not invent a link or claim it is playable.

Reddit, GitHub and other original sources are welcome as suggestions. The current published dataset supports X posts; other sources require editorial review and a schema update before publication.

## Corrections and removals

Open an issue identifying the case and the requested correction or removal. Include the original source where possible. Do not upload someone else's video, project files or private material.

## Pull requests

README.md is generated from a privately maintained catalog. Please suggest case additions and corrections through issues rather than editing the generated README directly. Improvements to contribution instructions and issue templates are welcome. This public repository contains no raw dataset or build tooling.
